HIMITRA Website
===============

This is the browser version of the HIMITRA Android demo.

Files:
- index.html — complete website; the UI, styling and demo interactions are self-contained.

How to run:
1. Extract the ZIP.
2. Double-click index.html to open it in Chrome/Edge, or use a local server.
3. For a local server with Python:
   python -m http.server 8000
   Then open http://localhost:8000

No backend is required for this demo.
